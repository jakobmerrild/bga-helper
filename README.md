## BGA Helper
Browser extension for utilities on https://baordgamearena.com (BGA).

### Red thumb helper
Displays all the players you have red-thumbed and all the players who have red-thumbed you.
Allows you to remove the red-thumb from players you have red-thumbed and red-thumb players back who
have red-thumbed you from within the extension side-bar.


## Installation
1. Download the source code, either by cloning the repository or by click the green `Code` button above and `Download Zip`
2. Unzip contents, if you downloaded the zip file
3. Go to chrome://extensions
4. Enable developer mode in top right corner if you haven't already
5. `Load unpacked` in the top left and point to the folder with the files
